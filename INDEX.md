# INDEX — карта репозитория

Репозиторий — база знаний ассистента косметолога клиники DERMATHEY. Он состоит из трёх слоёв: сырые источники (не редактируются), выжимка `knowledge/` и правила `rules/`.

## Для ассистента: с чего начинать

1. Прочитать `rules/source-hierarchy.md`: какому источнику верить и что запрещено.
2. Проверить `rules/KNOWN_ISSUES.md`: известные ошибки источников и что делать при каждой.
3. Отвечать по `knowledge/`. У каждого факта есть ссылка `путь:строка` на сырой источник.
