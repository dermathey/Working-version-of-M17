# Working-version-of-M17

Рабочая база знаний клиники **DERMATHEY**: материалы по аппарату-анализатору кожи **M17**, профессиональной косметике **HydroPeptide** и **md:complex / md:peel / md:ceuticals**, прайс клиники на 2026 год и учебники по косметологии.

Все файлы — Markdown, сконвертированные из PDF (частично через OCR). Иллюстрации в них не сохранились, многоколоночная вёрстка и таблицы во многих местах «поехали». Этот README — опись репозитория и список проблем, найденных при проверке. Проблемы отсортированы по важности.

## 3. Проблемы по файлам

### 3.1 `M17 User Manual.md`

- **Противоречия с брошюрой.** Здесь `Running platform: Android 8.1.0`, в брошюре `Android Version 12`. В п. 1.2.1 и 3.1.2 описан «RGB+UV+PL tri-spectrum», а в гл. 4 указано `Spectrums: 10 Spectrums`. В п. 7.4.2 говорится о «top 10 deep skin issues», в 7.6.2–7.6.3 — о «12 kinds of analysis», а в брошюре показателей 18.
- **Ошибка перевода, опасная для пользователя.** В п. 10.3 написано: «please remember to control the instrument **with wet hands**». В п. 1.2.5.4 (b) это прямо запрещено: «Do not touch the device with wet hands». В оригинале, видимо, было «do not…».
- «**Portable** General Purpose Equipment» (п. 2.2) при массе нетто 5 кг и брутто 9 кг и габаритах 60×45×22 см.
- Пропуски и опечатки: `Ambient temperature … 0°C ~40` (нет «°C»), `110-230 VAC =10%` (должно быть ±10%), обрыв фразы «…replace electrical and mechanic», `2.2 Safe Usel`, `Confirm nsssword`, `2000W pixel` (имеется в виду 20 МП).
- В п. 7.9 ссылка на «Picture 8-1», а под рисунком подпись «Picture 9-1».
- Таблица неисправностей (гл. 8) развалилась: пропал номер 2, причины и способы устранения перемешаны.
- Номера страниц оглавления оторваны от пунктов и идут отдельным столбцом.
- Подписи к скриншотам распознаны как мусор («Tarne», «Adverting», «Bittion», «Femare»…).
- Адрес облака указан по **http** (`http://analysis.milisun.com/login.aspx`), то есть логин и пароль передаются без шифрования.
- В упаковочном листе (Packing List) количество указано только у первой позиции.

### 3.11 `★ ★ ★ DERMATHEY ПРАЙС 2026_АППАРАТЫ_УХОД.md` — самый важный для работы

- **Съехавшие заголовки разделов.** Название нового раздела склеилось с последней строкой предыдущего, а цена стоит в конце. Примеры:
  - `|Ноги полностью + бикини глубокое + подмышки ЛАЗЕРНАЯ ЭПИЛЯЦИЯ / ПО ЗОНАМ / МУЖЧИНЫ*|460|`
  - `|Тело полностью ЛАЗЕРНОЕ УДАЛЕНИЕ ПИГМЕНТНЫХ ПЯТЕН (тариф за сеанс)|960|`
  - `|До 21 см² ДЕТАТУАЖ ЛАЗЕРОМ (тариф за сеанс)|300|`
  - `|4 сеанса / экономия 150 евро Интимная зона женщины (процедура «Крылья бабочки»)|1850|`
  - `|4 сеанса / экономия 150 - 200 евро BBL FOREVER YOUNG / ФОТООМОЛОЖЕНИЕ … Лицо|1250 - 1600|`
  - `|90 минут УХОДОВЫЕ ПРОЦЕДУРЫ ДЛЯ ЛИЦА HYDROPEPTIDE (США)**|150|`

  Из-за этого легко отнести цену не к той услуге. Особенно это опасно при автоматическом чтении (боты, поиск).
- **Опечатка в цене**: детатуаж, «До 8 см² — **1402**». Судя по соседним строкам, должно быть 140 (пигмент и сосуды — 140).
- Непоследовательная шкала у фракционного омоложения: 12 см² — 150, 16 см² — **270** (скачок), тогда как у пигмента и сосудов 190 → 240.
- Валюта не указана ни в одной колонке цен. Евро видно только из фраз «экономия … евро».

## 4. Проблемы, общие для нескольких файлов

1. **Нет единого источника по HydroPeptide.** Протоколы и продукты описаны в пяти файлах (EN-гайд ×2, Men's Facial, две русские методички, Esthetics Guide 2019), и они расходятся. Пример — мужской уход «ЭГОИСТ» / Re-Fueling Men's Facial:

   | Шаг | `HydroPeptide Refueling Men's Facial.md` (EN) | `HydroPeptide_методичка.md` (RU) |
   |---|---|---|
   | Пилинг 1 | **Apple Peel 1**, 2 мин | **Vitamin C Peel 1**, 1–3 мин |
   | Экспозиция пилингов | до 6 мин | ещё 5 мин после массажа |
   | Маска | **10–15 мин** | **7–10 мин** |
   | Экстракция | Clarifying Toner | Pre-Treatment Toner |
   | Порядок финиша | глаза → крем → SPF → губы | крем → SPF → глаза, без губ |
   | Дозировки | в чайных ложках | в мл |

2. **Названия процедур в прайсе и методичках не совпадают** (см. 3.11).
3. **Смешение кириллицы и латиницы** в одном слове есть почти во всех русских файлах: поиск по «SPA», «Multiprogram», «Perfection» не находит часть вхождений.
4. **Иллюстрации нигде не сохранились**, при этом текст на них постоянно ссылается («Picture 4-1», «Рис.», «ДО / ПОСЛЕ»).
5. **Заголовки** проставлены конвертером по размеру шрифта, а не по смыслу. Навигация по `#` в большинстве файлов бесполезна.
6. **Имена файлов**: пробелы, скобки, `&`, `+`, `[112558]`, `★`, суффиксы «(1) (1)». Такие имена неудобны в командной строке и в ссылках.
7. **Правовой аспект.** Учебники (Федотов и др., Марголина/Эрнандес) защищены авторским правом. Если репозиторий публичный, их лучше убрать или сделать репозиторий приватным. Рекламные утверждения брендов («блокирует меланин», «выявляет свинец/ртуть», «рост новых волос») нельзя переносить в материалы клиники для пациентов без проверки.
